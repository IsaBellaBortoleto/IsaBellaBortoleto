# 🔍 Check out my projects

## 🔌 Electronics & Embedded Systems
- **[HDB3 Line Coding](https://github.com/IsaBellaBortoleto/codificacao_de_linha)** — Real communication system between multiple computers implementing HDB3 line coding, using three ESP32 boards as radio links (ESP-NOW) and a Python desktop GUI with XOR encryption, extended ASCII encoding and waveform plotting *(Python · C++ · ESP32)*
- **[16-bit Microprocessor](https://github.com/IsaBellaBortoleto/microprocessador_v2)** — Custom accumulator-based 16-bit microprocessor designed from scratch in VHDL, with ALU, control unit, register bank, RAM/ROM and its own assembly instruction set — simulated with GHDL + GTKWave *(VHDL)*
- **[AirDrums](https://github.com/IsaBellaBortoleto/AirDrums)** — Virtual drum kit controlled by motion using ESP32
- **[Arboretum](https://github.com/IsaBellaBortoleto/UTFPR/blob/5f7e1228ab3bf1c1e42d204be3814ac6cc9ec2e0/1%20Periodo/Arboretum)** — Plant monitoring system with sensors
